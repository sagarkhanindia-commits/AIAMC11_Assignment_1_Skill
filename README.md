## Overview

This skill acts as an intelligent **Job Hunter** tailored for the **PAN India** job market. It accepts a candidate's **CV in any format** (such as PDF, DOCX, TXT, image, or pasted text) and automates job discovery, skill-gap analysis, and reporting.

### How It Works

1. **CV Format Verification:**
   The skill first validates whether the uploaded input is a genuine CV. If the file is not a CV, execution stops immediately and returns the message:
   > *"It is not CV format. Kindly upload correct CV."*

2. **Top 10 Job Portal Search & Profile Matching (PAN India):**
   Once a valid CV is confirmed, the skill scans the **top 10 job posting websites** for opportunities strictly across **PAN India**, comparing the job requirements against the skills and experience listed in your CV.

3. **100% Matched Jobs Report:**
   When a job achieves a **100% match** in both skill set and experience, the skill compiles a detailed listing containing:
   * **Job ID**
   * **Job Portal Name**
   * **Job Role**
   * **Job Description**
   * **Location** (PAN India)
   * **Apply Link**

4. **Near-Match Jobs (20% Skill Set Mismatch):**
   In addition to exact matches, the skill identifies high-potential jobs you missed by up to a **20% skill set mismatch**, highlighting the specific missing skills so you can see how close you are to qualifying.

5. **Hot Market Skills Gap Analysis:**
   The skill researches **trending, high-demand skills** in today's job market that are currently missing from your CV, helping you prioritize where to invest your learning time.

6. **PDF Output Generation:**
   Finally, the complete report—including 100% matched jobs, 20% mismatch opportunities, and recommended hot skills—is formatted and exported as a **downloadable PDF file**.
